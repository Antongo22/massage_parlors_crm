В качестве предметной области был выбран CRM для частного массажного салона. Этот домен достаточно реалистичен и при этом не перегружен специализированной логикой. Он естественным образом включает все необходимые сущности из задания: услуги, клиентов, запись на сеансы, абонементы, финансовый учет и коммуникацию с клиентами. Благодаря этому основное внимание можно уделить качеству архитектуры, бизнес-логике и расширяемости системы, а не особенностям узкоспециализированной отрасли.
