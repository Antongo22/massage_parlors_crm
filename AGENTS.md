# Инструкции для агентов

Перед изменением проекта полностью прочитайте [CLAUDE.md](CLAUDE.md). Несмотря
на историческое имя файла, это общий контракт для любого coding agent: команды
проверки, границы слоёв, инварианты модели и безопасный процесс миграций.

`README.md` описывает продукт и запуск, `docs/data-model.md` — связи и причины
ограничений, а структурные тесты БД являются исполняемым контрактом схемы.
